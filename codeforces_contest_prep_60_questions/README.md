# Codeforces Contest Prep

12 topic directories × 5 Python files each = 60 practice slots.

Each `.py` file contains:
- Problem title
- Direct Codeforces problem link
- A clean `solve()` template

Recommended progression:
01–07 first (implementation, math, brute force, strings, sorting, greedy, arrays/maps)
08–12 next (two pointers, prefix sums, binary search, bits, graphs)

Note: Some problems intentionally appear in more than one topic because they teach multiple patterns.
